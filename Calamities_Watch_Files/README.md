# Calamities Watch

Frontend prototype split from the uploaded `index(1).html`.

## Files
- `index.html` — page structure and external libraries
- `css/styles.css` — all existing styling
- `js/app.js` — map, weather, radar, reports, charts, and localStorage logic

## Current prototype functionality
- Leaflet interactive map
- User geolocation
- Rain radar toggle
- Weather card with mock-data fallback
- Citizen incident reporting
- Severity selection
- LocalStorage persistence
- Report markers and activity feed
- Chart.js report breakdown
- Responsive layout

## Planned integration points
- Replace mock weather with a production weather provider
- Add authenticated backend/database for cross-device reports
- Add official disaster feeds and data-source labels
- Add risk layers, alerts, emergency facilities, evacuation routes, and AI/risk models
